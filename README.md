## About This Repository

Welcome to **Smart Home Cambodia – Home Assistant Add-ons**.

This repository provides a collection of useful add-ons and tools designed to extend and improve your [Home Assistant](https://www.home-assistant.io/) smart home installation.

Our goal is to make smart home management easier, more powerful, secure, and accessible by bringing together useful tools for home automation, network management, remote access, and data backup.

Whether you are building a smart home, managing network infrastructure, or running your own home server, these add-ons are designed to help simplify your daily operations.

## Available Add-ons

This repository includes the following projects:

| Add-on / Project | Description |
|---|---|
| **MikroTik Manager** | Manage MikroTik RouterOS devices from Home Assistant, including network controls and management features. |
| **Cloudflared** | Connect Home Assistant remotely through secure Cloudflare Tunnels without opening router ports. |
| **NetBird** | Secure remote network connectivity using NetBird. |
| **Simple Scheduler** | Scheduling and automation management tools. |
| **Portainer** | Docker container management interface. |
| **Google Drive Backup** | Backup management using Google Drive. |
| **OneDrive Backup** | Backup management using Microsoft OneDrive. |
| **Samba Backup** | Backup management using Samba network storage. |
| **UniFi** | Tools and integrations for UniFi network management. |

For individual installation instructions and configuration options, please refer to the README inside each project folder.

## Installation

You can easily add this repository to your Home Assistant instance.

### Step 1 – Open Home Assistant

Navigate to:

**Settings → Add-ons → Add-on Store**

### Step 2 – Add Repository

1. Click the three-dot menu in the upper-right corner.
2. Select **Repositories**.
3. Add the following repository URL:

```text
https://github.com/smarthomekh/hasaddon
```

4. Click **Add**.

### Step 3 – Install an Add-on

1. Return to the Add-on Store.
2. Find the add-on you want to install.
3. Open its information page.
4. Click **Install**.
5. Configure the add-on according to its documentation.
6. Start the add-on.

**Congratulations!** Your Home Assistant installation can now use the add-ons available from this repository.

## Requirements

Before installing, make sure you have:

- A working Home Assistant installation.
- Access to the Home Assistant Add-on Store.
- An internet connection for downloading add-ons.
- Compatible hardware and architecture for the selected add-on.
- Any additional accounts, API credentials, or network configuration required by individual add-ons.

## Security & Privacy

Security is important when managing your smart home and network infrastructure.

We recommend:

- Use strong passwords and dedicated user accounts.
- Avoid exposing management interfaces directly to the public internet.
- Use secure remote access solutions such as Cloudflare Tunnel or NetBird.
- Keep Home Assistant and add-ons updated.
- Store API keys, tokens, and credentials securely.
- Review the security documentation before installing an add-on.
